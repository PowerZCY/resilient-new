# GitHub仓库可视化动画平台 - 实施计划

## 项目初始化

### 环境搭建
1. 创建Next.js项目
```bash
pnpm create next-app --typescript git-viz
cd git-viz
pnpm add -D tailwindcss postcss autoprefixer
pnpm dlx tailwindcss init -p
```

2. 安装核心依赖
```bash
pnpm add next-auth @prisma/client swr d3 three framer-motion next-intl
pnpm add -D prisma typescript @types/node @types/react @types/d3 @types/three
```

3. 安装UI组件库
```bash
pnpm add lucide-react @radix-ui/react-dialog @radix-ui/react-dropdown-menu @radix-ui/react-slider @radix-ui/react-tooltip
```

4. 初始化Prisma
```bash
pnpm prisma init
```

```
src/

│   ├── [locale]/           # 国际化路由
```
