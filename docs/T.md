# 时间轴卡片原型设计文档

## 整体架构

时间轴卡片原型是一个基于网页的交互式时间线展示组件，采用3D环绕效果呈现信件风格的卡片，主要由以下部分组成：

1. **HTML结构**：包含标题、分组导航、卡片展示区域和模态框
2. **数据模型**：通过timeline-data.js提供的数据结构驱动展示
3. **交互逻辑**：通过timeline-card.js实现卡片的3D环绕效果和交互
4. **样式设计**：使用timeline-card.css实现信件风格的UI效果

## 核心功能与设计细节

### 1. 数据结构设计

数据模型采用JSON格式，包含以下组成部分：
- **进度对象**：显示当前进度与总进度（96/192）
- **分组数组**：将卡片分为4个组，每组有独立ID和标签
- **卡片数组**：二维数组结构，每个分组包含多个卡片记录
- **卡片对象**：包含ID、日期、内容和是否需要渐变遮罩等属性

```javascript
const timelineData = {
  progress: { current: 96, total: 192 },
  groups: [{ id: 0, label: "1" }, ...],
  cards: [[card1, card2, ...], [card11, card12, ...], ...]
};
```

### 2. 导航组按钮设计

导航按钮采用现代化圆形设计，具有以下特点：

- **视觉样式**：
  - 圆形按钮，白色背景，紫色边框
  - 激活状态为紫色填充，白色文字
  - 激活状态添加光晕效果，带有脉动动画
  - 按钮水平排列，居中于页面底部

- **交互效果**：
  - 悬停时按钮缩放1.1倍并增加阴影
  - 点击时按钮变为激活状态，同时触发分组切换
  - 动画过渡平滑，采用ease曲线

- **技术实现**：
  - 使用CSS的`transform`和`box-shadow`属性实现视觉效果
  - 通过`@keyframes pulse`实现脉动动画
  - 导航按钮通过JavaScript动态生成，确保与数据同步

### 3. 卡片样式设计

采用信件风格的卡片设计，主要特点包括：

- **基础样式**：
  - 卡片尺寸：180px × 280px
  - 圆角边框：12px
  - 信纸米黄色背景(#fffef0)
  - 轻微的阴影效果增强立体感

- **信件元素**：
  - 背景带有横纵交错的线条模拟信纸纹理
  - 左上角添加邮票装饰元素
  - 内容区使用楷体字体(汉仪悠然体/华文楷体)
  - 文本区域有横线背景，类似笔记本纸张

- **日期标签**：
  - 位于卡片顶部居中，微微突出
  - 紫色背景，白色文字，圆角设计
  - 使用Times New Roman字体强调时间属性

- **卡片底部**：
  - 使用虚线分隔底部操作区
  - 包含互动图标，如点赞、收藏等功能

- **状态变化**：
  - 普通状态：透明度较低的内容显示
  - 悬停状态：透明度提高，轻微放大，添加紫色边框和阴影
  - 激活状态：完全不透明，明显放大，增强阴影效果

### 4. 动画效果设计

整个组件采用丰富的动画效果，提供流畅的视觉体验：

- **初始发牌动画**：
  - 中央卡片从导航按钮位置开始，以小比例缩放并完全透明
  - 通过2.5秒的多步动画，卡片逐渐放大、旋转两圈(720度)并增加透明度
  - 采用30个小步骤实现平滑过渡，避免生硬变化
  - 卡片完成主要动画后，周围的卡片以波浪效果依次淡入

- **卡片环绕效果**：
  - 卡片围绕中心点以半径550px圆形排列
  - 利用三角函数计算每张卡片的准确3D位置
  - 卡片根据离中心的距离调整Z轴深度和透明度
  - 远离中心的卡片透明度逐渐降低，创造空间感

- **卡片点击动画**：
  - 点击非中心卡片时，整个环绕视图旋转
  - 被点击的卡片平滑过渡到中心位置
  - 其他卡片同步调整位置，保持整体环形排列

- **分组切换动画**：
  - 点击不同导航按钮时，当前分组卡片淡出
  - 新分组的中央卡片从导航按钮位置"弹出"
  - 完成中央卡片动画后，周围卡片以波浪效果依次淡入
  - 左右两侧的卡片出现时间错开，增强层次感

- **光晕与悬停效果**：
  - 卡片悬停时添加光晕效果，通过`glow-pulse`动画实现
  - 激活的导航按钮周围有脉动光环
  - 信件边缘在拖动时出现脉动边框动画

### 5. 交互设计细节

组件提供丰富的交互体验，主要包括：

- **卡片内容查看**：
  - 默认显示截断的内容，超出部分用渐变遮罩提示
  - 点击活跃状态(中央)卡片内容，打开模态框查看完整内容
  - 模态框包含关闭按钮和"点击空白处关闭"提示

- **卡片导航**：
  - 点击任意可见卡片，使其旋转到中心位置
  - 点击底部导航按钮，切换不同分组的卡片
  - 环绕效果使最多10张卡片同时可见，其余卡片根据透明度和位置隐藏

- **进度指示器**：
  - 圆形悬浮球设计，显示当前进度百分比和具体数值
  - 支持拖拽到屏幕任意位置，位置会被保存
  - 指示器显示当前激活卡片的ID

- **触摸支持**：
  - 全面支持触摸事件，适配移动设备
  - 进度指示器可通过触摸拖动
  - 模态框支持触摸关闭

### 6. 性能优化措施

组件在设计时考虑了性能优化：

- **渲染优化**：
  - 使用`will-change`属性提前告知浏览器元素将变化
  - 添加`transform: translateZ(0)`启用GPU加速
  - 非可见卡片设置`visibility: hidden`减少渲染计算

- **动画优化**：
  - 使用`requestAnimationFrame`代替`setTimeout`实现动画
  - 分步渲染复杂动画，避免卡顿
  - 仅对可见元素应用动画效果

- **事件处理**：
  - 使用事件委托减少事件监听器数量
  - 降低不必要的DOM操作频率
  - 优化事件处理函数，避免频繁计算

## 技术实现要点

### 卡片渲染与定位

卡片在3D空间的排列通过以下数学计算实现：

```javascript
const angle = relativePos * (VISIBLE_ANGLE / VISIBLE_CARDS);
const x = Math.sin(angle) * RADIUS;
const y = -40 + Math.abs(relativePos) * 5;
const z = Math.cos(angle) * RADIUS * 0.7;
const rotateY = -angle * 0.8;
```

### 响应式适配

组件通过以下方式实现响应式设计：

- 使用相对单位和百分比布局
- 视口尺寸变化时重新计算卡片位置
- 通过CSS媒体查询适配不同设备
