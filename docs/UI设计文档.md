# GitHub仓库可视化动画平台 - UI设计文档

## 设计原则

1. **简洁优雅**：遵循JetBrains设计语言，简洁而不简单
2. **直观易用**：控件布局符合用户心智模型
3. **视觉层次**：清晰的信息层级和视觉引导
4. **响应式**：适配从移动设备到大屏显示器的各种尺寸
5. **一致性**：统一的设计语言和交互模式

## 色彩系统

### 主色调
- 主色：#4F46E5（靛蓝色）
- 辅助色：#EC4899（粉色）
- 中性色：#F9FAFB至#111827（灰度梯度）

### 功能色
- 成功：#10B981
- 警告：#F59E0B
- 错误：#EF4444
- 信息：#3B82F6

## 排版系统

- 主标题：Inter, 24px, 700 weight
- 副标题：Inter, 20px, 600 weight
- 正文：Inter, 16px, 400 weight
- 小字体：Inter, 14px, 400 weight
- 代码：JetBrains Mono, 14px

## 组件设计

### 导航栏
- 固定在顶部
- 包含logo、导航链接和用户头像
- 暗色背景，白色文字
- 响应式设计，在移动设备上转为汉堡菜单

### 仓库卡片
- 圆角矩形设计
- 显示仓库名称、描述、星标数和最后更新时间
- 悬停效果：轻微阴影增强和背景色变化
- 点击进入详情页

### 可视化控制面板
- 半透明浮动面板
- 包含播放/暂停按钮、速度滑块、时间轴
- 可折叠的高级设置区域
- 位于可视化区域底部

### 可视化画布
- 占据主要视口区域
- 深色背景以突出可视化元素
- 支持鼠标拖拽、缩放操作
- 右下角显示迷你地图

### 数据卡片
- 简洁的数据展示组件
- 大字体显示关键数字
- 包含微型趋势图
- 网格布局，响应式调整

### 按钮系统
- 主按钮：填充色背景，白色文字
- 次要按钮：描边样式，主色文字
- 图标按钮：仅图标，悬停显示提示文本
- 禁用状态：降低透明度，移除交互效果

## 页面布局

### 首页
- 顶部：品牌标识和简短介绍
- 中部：产品特性展示，配以动画插图
- 底部：号召性用语和"使用GitHub登录"按钮
- 页脚：导航链接、版权信息

### 仓库列表页
- 顶部：搜索栏和筛选选项
- 主体：网格布局的仓库卡片
- 右侧：用户信息和统计数据
- 分页控件位于底部

### 可视化页面
- 左侧：仓库信息和基本统计
- 中央：大型可视化画布
- 底部：时间轴和控制面板
- 右侧：可折叠的设置面板

### 设置页面
- 分类标签页导航
- 表单布局的设置项
- 即时预览效果
- 底部保存/取消按钮

## 响应式设计策略

### 移动设备 (< 768px)
- 单列布局
- 折叠导航为汉堡菜单
- 简化控制面板
- 可视化区域占满屏幕宽度

### 平板设备 (768px - 1024px)
- 双列布局
- 部分功能区域可折叠
- 调整卡片大小以适应屏幕

### 桌面设备 (> 1024px)
- 多列布局
- 展开所有功能区域
- 大型可视化画布

## 动画与过渡

- 页面切换：淡入淡出效果
- 组件加载：渐进式显示
- 交互反馈：微妙的缩放和颜色变化
- 数据更新：平滑过渡

## 可访问性考虑

- 符合WCAG 2.1 AA标准
- 适当的颜色对比度
- 键盘导航支持
- 屏幕阅读器兼容性
